Li Battery Connect 真机安装

iOS Ad Hoc 1.0.5 (5) · Android 1.0.6 (6)

iOS 安装需要系统 Safari

itms-services:// 只在 iPhone / iPad 的系统 Safari 里生效；微信「扫一扫」、Chrome、QQ 浏览器、电脑浏览器点了都不会有反应。Android 手机请直接点下方蓝色 APK 按钮，不受此限制。

检测到 Android 设备：点下面蓝色按钮下载 APK，下载完成后打开即可安装。

iPhone / iPad

安装到 iPhone / iPad

弹「是否安装 Li Battery Connect」后点安装，回桌面等图标出现。

备用安装入口（GitHub Release manifest）

Android 手机 / 平板

下载 Android APK（1.0.6）

无需 UDID、无需描述文件，任意 Android 设备都能装。APK 约 77 MB，建议用 Wi-Fi。

打不开？去 Release 页面下载

下载完点开 APK → 系统提示「允许安装未知应用」时打开开关 → 点安装。本包与 1.0.1 旧版同包名同签名，可直接覆盖安装；若提示「应用未安装」再卸载旧版。

iOS 按钮没反应？手动复制链接

长按文本框全选复制 → 打开 Safari → 粘贴到地址栏 → 回车。这是最可靠的方式。

iOS 安装后

  1. 首次点开若提示「未受信任的开发者」：设置 → 通用 → VPN 与设备管理 → 信任 JIE LI (TWPHU4MQ8G)。
  2. 首次启动需要联网，设备要能访问 https://ppq.apple.com（在线证书校验）。
  3. 只有已登记 UDID 的 2 台设备能安装，其它设备会报 0xE8008015。

注意

  1. 本页与安装包均为公开链接，请勿转发给无关人员。
  2. Android 首次使用请允许蓝牙 / 附近设备 / 相机权限，否则自动扫描与扫码连不上设备。
  3. 若提示「无法下载应用程序」，多为网络问题（尤其访问 GitHub Release），可换网络重试。
  4. iOS 描述文件到期 2027-11-04，到期后需重新生成 profile、重签并重装。
