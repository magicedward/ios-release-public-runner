Li Battery Connect 真机安装

Ad Hoc · 1.0.5 (5) · 描述文件有效期至 2027-11-04

当前不是 iOS 系统 Safari

itms-services:// 只在 iPhone / iPad 的系统 Safari 里生效。用 iPhone 相机扫二维码并在 Safari 打开，或复制下方链接粘到 Safari 地址栏。微信「扫一扫」、Chrome、QQ 浏览器、电脑浏览器点了都不会有反应。

点下面的按钮安装

安装到 iPhone / iPad

弹「是否安装 Li Battery Connect」后点安装，回桌面等图标出现。

备用安装入口（GitHub Release manifest）

按钮没反应？手动复制链接

长按文本框全选复制 → 打开 Safari → 粘贴到地址栏 → 回车。这是最可靠的方式。

备用链接：

安装后

  1. 首次点开若提示「未受信任的开发者」：设置 → 通用 → VPN 与设备管理 → 信任 JIE LI (TWPHU4MQ8G)。
  2. 首次启动需要联网，设备要能访问 https://ppq.apple.com（在线证书校验）。
  3. 只有已登记 UDID 的 2 台设备能安装，其它设备会报 0xE8008015。

注意

  1. 本页与 IPA 均为公开链接，请勿转发给无关人员。
  2. 若提示「无法下载应用程序」，多为网络问题（尤其访问 GitHub Release 的 IPA），可换网络重试。
  3. 描述文件到期 2027-11-04，到期后需重新生成 profile、重签并重装。
manifest 必须为 HTTPS 且返回 XML；签名: Apple Distribution: JIE LI (TWPHU4MQ8G)
